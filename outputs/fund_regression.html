2018 Fund Returns

Multiple linear regression · Nine predictors · Diagnostics and inference

Before you start

Run the code blocks from top to bottom. Each block uses results from the ones above it. <- saves a result under a name, $ selects a column, and # starts a comment explaining the code.

We use only the 2018 return and the nine chosen predictors. Values stay in their original units: a return of 0.05 means 5%. No logs, rescaling, transformations, or model corrections are applied.

1. Read the two files

read.csv() reads a CSV file into a table. NA means a missing value.

etfs <- read.csv("data/ETFs.csv", na.strings = c("", "NA"))
mutualfunds <- read.csv("data/MutualFunds.csv", na.strings = c("", "NA"))

2. Keep the columns we need

c() makes a list of column names. In [rows, columns], leaving the row position blank keeps every row.

columns <- c(
  "fund_symbol",
  "fund_return_2018",
  "fund_annual_report_net_expense_ratio",
  "total_net_assets",
  "inception_date",
  "asset_stocks",
  "asset_bonds",
  "annual_holdings_turnover",
  "fund_price_earning_ratio",
  "fund_sector_technology"
)

etfs <- etfs[, columns]
mutualfunds <- mutualfunds[, columns]

# Label each fund: 1 means ETF, 0 means mutual fund.
etfs$etf_indicator <- 1
mutualfunds$etf_indicator <- 0

# Stack the two tables into one table.
funds <- rbind(etfs, mutualfunds)

3. Calculate fund age

Convert inception dates into dates R understands. Subtracting dates gives the number of days between them; dividing by 365.25 gives approximate years. This and the ETF indicator are the only derived predictors.

funds$inception_date <- as.Date(funds$inception_date)

funds$fund_age_years <- as.numeric(
  as.Date("2018-01-01") - funds$inception_date
) / 365.25

# A fund launched after January 1, 2018 has no applicable age at that date.
funds$fund_age_years[funds$fund_age_years < 0] <- NA

6. Fit the multiple linear regression

lm() fits a linear regression. The response goes to the left of ~, and the predictors go to the right. + adds another predictor to the model.

model <- lm(
  fund_return_2018 ~ etf_indicator +
    fund_annual_report_net_expense_ratio +
    total_net_assets +
    fund_age_years +
    asset_stocks +
    asset_bonds +
    annual_holdings_turnover +
    fund_price_earning_ratio +
    fund_sector_technology,
  data = model_data
)

8. Check the regression assumptions

R already provides the main diagnostic plots, so we can draw them directly. These plots help identify problems to fix later; they do not fix the model.

Residuals versus fitted: look for residuals scattered around zero, without curvature or a funnel shape.

plot(model, which = 1)

Normal Q-Q: points close to the line support approximately normal errors. Large departures, especially at the ends, suggest non-normal tails.

plot(model, which = 2)

Scale-location: a roughly horizontal trend and even spread support constant error variance. The plotted residuals are standardized only for the diagnostic; the regression still uses the original return.

plot(model, which = 3)

Residuals versus leverage: observations far to the right have unusual predictor combinations. Large residuals and high leverage together merit review.

plot(model, which = 5, cook.levels = numeric(0))

Keep in mind

This is the starting model. Use the diagnostics to decide what needs work later. Ordinary confidence intervals and hypothesis tests rely on model assumptions, including independent errors and constant variance.

The source files contain reporting dates from 2021, so predictor values are not confirmed to describe funds before 2018. Missing data and multiple share classes of the same fund can also affect conclusions. These limitations are not resolved by fitting the regression.
